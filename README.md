# 紅の豚 ファンサイト — Porco Rosso fan website

スタジオジブリの映画『紅の豚』のファンサイト（HAL東京の課題 WF15-05）
*Fan website for the Studio Ghibli film Porco Rosso (HAL Tokyo assignment WF15-05).*

**公開サイト / Live site:** https://ambitious-rock-08ecb2600.5.azurestaticapps.net/

## 内容 / What's inside

- HTML / CSS（パソコン画面用 / desktop layout）
- 4ページ：トップ、キャラクター、声優、海 / 4 pages: home, characters, voice cast, the sea
- Azure Static Web Apps でホスティング / hosted on Azure Static Web Apps

## デザインの考え方 / Design intent

映画の自由さに敬意を表して、余白を大きく取りました。キャラクターと物語を現実の自然につなぐため、海と島がいつも見えるようにしています。飾りすぎず、雑誌のように気持ちよく読めるサイトを目指しました。

*Lots of white space, as a tribute to the freedom of the film. The sea and the islands are always visible, to anchor the characters in real nature. The goal was a site that reads like a pleasant magazine, without frills.*
